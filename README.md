# 履带式巡检车 - 项目进度汇报平台

基于 Node.js + Express 的静态网页，用于展示履带式巡检车项目的开发进度。

## 快速开始

```bash
npm install
npm start
```

访问 http://localhost:3000

## 技术栈

- Node.js + Express
- 纯 HTML/CSS/JS
- Canvas 动态背景
- 响应式设计

## 项目结构

```
├── server.js          # Express 服务器
├── package.json       # 项目配置
├── public/
│   ├── index.html     # 主页面
│   ├── css/
│   │   └── style.css  # 科技感样式
│   └── js/
│       └── main.js    # 交互动效
└── README.md
```
