## 本周进展

### 环境搭建 (Ubuntu 22.04 + VS Code)

- ✅ **Android SDK 完整安装与配置**
  - 下载 Android SDK (API 21 ~ 35)
  - 配置 `ANDROID_HOME`、`ANDROID_SDK_ROOT` 环境变量
  - 安装 platform-tools (adb, fastboot)
  - 配置 Android NDK r27c
- ✅ **中国大陆网络加速方案**
  - Android SDK Manager 镜像配置 (东软/中科大镜像源)

- ✅ **VS Code 开发环境搭建**

## 经验小结

- Gradle 阿里云镜像可将依赖下载速度从 KB/s 提升至 MB/s
- Qt for Android 环境需同时配置 NDK + SDK + JDK 三个路径
- Android 模拟器在 KVM 加速下性能接近真机，适合日常开发调试
