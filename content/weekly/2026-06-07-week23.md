## 本周进展

### AGV 导航系统全链路联调

- 🔄 三端联调: Android平板 + Windows PC + 树莓派控制中心
  - 统一 API 调用规范 (Bearer Token 统一管理)
  - 多端同时连接测试 (连接池压力验证)
  - 指令同步: 任一端发送控制指令，其他端状态实时更新
- 🔄 底盘 CAN 驱动实机验证
  - 树莓派 USB-CAN 适配器 → TK-mid 底盘
  - 运动学控制精度测试 (直线/转向/原地旋转)
  - 里程计数据回读验证
- ⬜ MJPEG 视频延迟优化
  - 目标: 局域网 < 150ms，跨网段 < 500ms

### 快直播推流集成

- 🔄 推流服务与 AGV 导航 APP 对接
  - 导航 APP 内嵌 WebRTC 播放器 (QML WebView)
  - 推流启动/停止指令集成到任务链
  - 推流状态实时显示 (帧率/码率/延迟)
- 🔄 多摄像头支持扩展
  - 海康 SDK + USB 摄像头双路视频
  - 视频源切换与画中画模式
- ⬜ 云端录制与回放功能

### 海康摄像头自动巡检

- 🔄 PTZ 预置位巡检流程开发
  - 预置位序列编辑 (1→2→3→...→N)
  - 每点自动: 转到位 → 稳定 2s → 抓拍 → 上传云端 → 下一位置
  - 巡检进度实时显示 (3/10 完成)
- ⬜ 异常检测: 画面分析 (模糊/遮挡/角度偏移)

### 语音广播系统部署

- 🔄 树莓派端 systemd 服务配置
  - 开机自启 + 崩溃自动重启
  - 日志轮转 (logrotate)
- 🔄 与任务链集成: "巡检点3 → 拍照 → 语音播报'3号巡检点检查完成'"
- ⬜ 多区域同步广播测试
