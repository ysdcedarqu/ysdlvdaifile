## 本周进展

### AGV 导航 APP v1.0.0 正式发布 (anzhuodaohang/AGVNav)

**技术栈**: Qt 6.8.3 + QML + C++ → Android (arm64-v8a)  
**目标设备**: 小米平板 (adb ID: `1c7d8049`)  
**连接后端**: 机器人 HTTP API (`192.168.1.102:8888`) + 树莓派控制中心 (`:5003`)
**产物**: `libAGVNav_arm64-v8a.so` + QML UI → APK

---

#### 1. 任务链编辑与执行引擎

- ✅ **可视化任务链编辑器**
  - QML `ListView` + `DragHandler` 实现拖拽式任务编排
  - 支持任务类型: 导航到点、等待延时、拍照存证、TTS 喊话、GPIO 控制
  - 每个任务可配置参数: 目标点、速度(m/s)、超时时间(s)、重试次数
- ✅ **任务链执行引擎**
  - 状态机模型: 等待中 → 执行中 → 成功 / 失败 / 超时
  - 支持条件跳转 (上一任务失败时跳至指定任务或终止)
  - 执行日志实时输出 (带时间戳)
  - 手动暂停/继续/终止

#### 2. MJPEG 视频流集成

- ✅ **海康摄像头视频流接入**
  - 数据链路: 海康摄像头 → 树莓派 C++ PTZ Server (TCP `:9988`) → MJPEG Stream (`:9990`) → QML `AnimatedImage`
  - 局域网延迟 < 200ms
- ✅ **视频优化**
  - QML 配置: `Image { cache: false }` 禁用缓存保证实时性
  - 断线自动重连 (指数退避, 最大间隔 5s)
  - 流地址格式: `http://{树莓派IP}:9990/video/mjpeg`

#### 3. TTS 喊话功能

- ✅ Android `TextToSpeech` 引擎集成
  - 中英文语音播报 (自动检测语言)
  - 语速 (0.5x ~ 2.0x)、音调可调
  - 预设喊话模板: 警告语、状态提示、巡检播报
  - 支持任务链中嵌入喊话步骤

#### 4. 导航点管理系统

- ✅ **导航点 CRUD**
  - 地图长按添加、点击编辑、滑动删除
  - 导航点属性: 名称、经纬度、备注、排序号
  - 支持 JSON 格式导入/导出 (用于任务链配置迁移)
- ✅ **路径规划集成**
  - 调用机器人 HTTP API 开始建图: `GET /yhs-robot/cmd/begin_map?map_name={name}`
  - 停止扫描: `GET /yhs-robot/cmd/async_stop_scan_map` (注意: 必须用 GET!)
  - 导航指令: `POST /yhs-robot/cmd/navigate` + 目标点 JSON

#### 5. 地图编辑器

- ✅ **四顶点弹窗绘制工具**
  - 在地图上依次点击四个顶点, 自动生成四边形巡检区域
  - 实时预览: 半透明蓝色填充 + 白色描边
  - 区域属性编辑: 名称、颜色、透明度
  - 使用 Qt6 `MapPolygon`: `import QtLocation 6.8` + `import QtPositioning 6.8`
- ✅ **多地图源切换**
  - OpenStreetMap (在线, 默认)
  - 离线瓦片地图: 预下载 PNG 瓦片, 使用 `file://` 本地 URI
  - `osm_providers.json` 配置文件管理多源:
    ```json
    {
      "providers": [
        {"name": "OSM", "url": "https://tile.openstreetmap.org/{z}/{x}/{y}.png"},
        {"name": "Offline", "url": "file:///sdcard/tiles/{z}/{x}/{y}.png"}
      ]
    }
    ```
- ✅ 区域管理: 增删改查巡检区域、区域与导航点关联

#### 6. 摇杆控制

- ✅ **虚拟摇杆 (DPadButton 组件)**
  - 8 方向: 上下左右 + 四对角 (左上/右上/左下/右下)
  - 触摸力度感应: 离中心越远速度越快
  - 长按连续发送速度指令 (50ms 间隔), 松开自动发送 STOP
- ✅ **速度实时显示**
  - 轮询机器人 API (500ms 间隔) 获取实时速度
  - Cyber 风格仪表盘: 环形进度条 + 数字读数
  - 线速度 (m/s) + 角速度 (rad/s) 双显示

#### 7. 自研 Cyber 科技风 UI 组件库

全部 QML 组件独立封装, 可在其他 Qt 项目复用:

| 组件 | 说明 |
|------|------|
| `CyberButton` | 霓虹发光按钮 (hover 光晕、press 缩放动画) |
| `DPadButton` | 8 方向虚拟摇杆 (力度感应) |
| `DeviceStatus` | 设备状态面板 (在线/离线、电量、信号) |
| `InfoCard` | 通用信息卡片 (标题、数值、趋势箭头) |
| `MapInfoCard` | 地图浮层信息卡 (当前坐标、缩放级别) |
| `MapView` | 地图显示组件 (封装 QML Map + 手势) |
| `MappingPage` | 建图页面 (开始/停止/保存地图) |
| `RobotMap` | 机器人位姿实时显示 (箭头图标 + 朝向) |
| `MapEditor` | 地图区域编辑器 (四顶点绘制) |
