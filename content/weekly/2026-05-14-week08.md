**技术栈**: Qt 6.8.3 + QML + C++ → Android (arm64-v8a)  
**目标设备**: 小米平板 (adb ID: `1c7d8049`)  
**连接后端**: 机器人 HTTP API (`192.168.1.102:8888`) + 树莓派控制中心 (`:5003`)

#### 1. 任务链编辑与执行引擎

- ✅ **可视化任务链编辑器**
  - 拖拽式任务编排 (QML `ListView` + `DragHandler`)
  - 支持任务类型: 导航、等待、拍照、喊话、IO 控制
  - 任务参数配置面板 (起点/终点/速度/超时)
- ✅ **任务链执行引擎**
  - 顺序执行 + 条件跳转
  - 实时状态反馈 (等待中 → 执行中 → 成功/失败)
  - 执行日志实时输出

#### 2. MJPEG 视频流集成

- ✅ **海康摄像头视频流接入**
  - 连接树莓派 PTZ Server → 海康 SDK → MJPEG Stream (:9990)
  - QML `AnimatedImage` 组件实时渲染
  - 视频延迟 < 200ms (局域网)
- ✅ **视频缓存优化**
  - `Image { cache: false }` 禁用缓存保证实时性
  - URL 时间戳强制刷新: `source: url + "?t=" + Date.now()`

#### 3. TTS 喊话功能

- ✅ Android TextToSpeech 引擎集成
  - 支持中英文语音播报
  - 语速/音调可调
  - 预设喊话模板 (警告/提示/状态播报)

#### 4. 导航点管理系统

- ✅ **导航点 CRUD**
  - 地图长按添加导航点
  - 导航点命名、排序、拖拽调整
  - 支持导入/导出 JSON 格式
- ✅ **路径规划集成**
  - 调用机器人 API `/yhs-robot/cmd/begin_map` 开始建图
  - `/yhs-robot/cmd/async_stop_scan_map` (GET!) 停止扫描

#### 5. 地图编辑器

- ✅ **四顶点弹窗绘制工具**
  - 在地图上点击四个顶点自动生成四边形区域
  - 实时预览半透明填充
  - 区域命名 + 颜色自定义
- ✅ **多地图源切换**
  - OpenStreetMap (默认)
  - 离线瓦片地图 (本地 `file://` 协议)
  - `osm_providers.json` 配置多源
- ✅ **QML Map 组件集成要点**
  - `import QtLocation 6.8` + `import QtPositioning 6.8` (Qt6 路径变更)
  - `MapPolygon` 绘制区域、`MapCircle` 标记点

#### 6. 摇杆控制

### API 调试踩坑 (5 大教训)

| # | 现象 | 根因 | 发现方法 |
|---|------|------|----------|
| 1 | HTTP 400 | 空 body 误设 `Content-Type: application/json` | `curl -v` 对比 |
| 2 | HTTP 401 | `Authorization: {token}` 缺少 `Bearer ` 前缀 | curl 逐格式测试 |
| 3 | HTTP 405 | `async_stop_scan_map` 用 POST 实际要 GET | `curl -X GET` vs `-X POST` |
| 4 | 图片不显示 | `file://` URL Android 沙箱不可用 | 查看 Qt Android 文档 |
| 5 | Release 日志丢失 | `qDebug()` 被 `-DQT_NO_DEBUG` 移除 | 改用 `qWarning()` |

**核心原则**: 永远先用 `curl` 在 PC 上验证 API，再写 C++ 代码！
