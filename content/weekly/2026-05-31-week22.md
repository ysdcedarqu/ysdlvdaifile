## 本周进展

### 腾讯快直播推流 (yuanchengzhibotxy) — 重点突破

基于腾讯云快直播服务，实现 USB 摄像头画面超低延迟推流，
端到端延迟控制在 1 秒以内，满足远程巡检实时视频监控需求。

#### 系统架构

USB摄像头 → FFmpeg(H.264编码) → RTMP推流 → 腾讯快直播CDN → WebRTC播放(毫秒级延迟)

#### FFmpeg 低延迟编码参数优化

针对腾讯快直播进行 7 项关键参数调优：

| 参数 | 配置值 | 作用 |
|------|--------|------|
| 编码器 | libx264 | H.264 高性能软件编码 |
| preset | ultrafast | 最快编码速度，大幅降低编码缓冲延迟 |
| tune | zerolatency | 零延迟模式，关闭帧间参考缓冲 |
| profile | baseline | 基线配置，无B帧，兼容性最好 |
| GOP | 30帧(1秒) | 极短GOP减少关键帧等待 |
| B帧 | 禁用(-bf 0) | 彻底消除双向预测帧的编码延迟 |
| 码率 | 2500 Kbps | 720p画质与带宽最佳平衡点 |
| 分辨率 | 1280x720@30fps | 高清流畅，不过度消耗带宽 |

FFmpeg 完整推流命令：

```
ffmpeg -f v4l2 -i /dev/video0 -c:v libx264 -preset ultrafast
  -tune zerolatency -profile:v baseline -level 4.0 -g 30 -bf 0
  -b:v 2500k -r 30 -s 1280x720 -f flv rtmp://push-domain/live/xunjian
```

  - 腾讯云 WebRTC Player SDK 集成
  - Chrome 自动摄像头权限授权优化
- ✅ 双语言支持: Node.js(server.js) + Python(server.py)

#### 低延迟对比

| 优化项 | 常规直播 | 快直播优化后 |
|--------|----------|-------------|
| 编码 preset | medium | ultrafast |
| GOP 间隔 | 60帧(2s) | 30帧(1s) |
| B 帧 | 2 | 0(禁用) |
| 传输协议 | RTMP/TCP | WebRTC/UDP |
| 端到端延迟 | 3-5秒 | <1秒 |
