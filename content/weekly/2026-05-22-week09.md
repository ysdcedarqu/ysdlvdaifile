## 本周进展

### Windows 桌面版迁移 (windowsxunjianat)

将 AGVNav 从 Android (arm64-v8a) 完整迁移至 Windows 桌面平台：

- ✅ **Qt 桌面编译环境配置**
  - 切换构建套件: `android_arm64_v8a` → `gcc_64` (Desktop)
  - qmake 命令: `qmake6 AGVNav.pro` (无需 `-spec android-clang`)
  - 移除 Android 特定依赖 (Qt6Android.jar, AndroidManifest.xml)
- ✅ **UI 自适应适配**
  - Android 触摸控件 → Windows 鼠标/键盘交互
  - 窗口尺寸自适应 (平板竖屏 → PC 横屏)
  - 高 DPI 显示器适配 (Qt `AA_EnableHighDpiScaling`)
- ✅ **网络层跨平台兼容**
  - `QNetworkAccessManager` 代码零改动 (Qt 跨平台抽象)
  - HTTP API 调用全部兼容
  - MJPEG 视频流 Windows 端渲染验证
- ✅ **功能完整性验证**
  - 任务链编辑器 ✅
  - 地图编辑器 (OSM + 离线瓦片) ✅
  - 摇杆控制 (键盘 WASD 替代触摸) ✅
  - MJPEG 视频显示 ✅
  - TTS 喊话 (Windows SAPI 替代 Android TTS) ✅
- ✅ **Windows 版项目交接文档**

### 树莓派后端云端集成 (robothouduan)

- ✅ **云端巡检解析 API 接入**

## 技术要点

| 平台差异 | Android | Windows Desktop |
|----------|---------|-----------------|
| 构建工具链 | android-clang + NDK r27c | gcc_64 (MinGW/MSVC) |
| 安装方式 | adb install APK | 直接运行 .exe |
| 触摸交互 | QML TouchHandler | MouseArea + 键盘 |
| TTS 引擎 | Android TextToSpeech | Windows SAPI |
| 文件访问 | 沙箱限制 | 无限制 |
| 高 DPI | 自动缩放 | AA_EnableHighDpiScaling |
